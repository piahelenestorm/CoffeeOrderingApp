\# Coffee Ordering App ☕



A fullstack coffee ordering application built as a learning project.



\## Tech stack



\*\*Frontend\*\*

\- Angular 22

\- TypeScript

\- RxJS Observables

\- Angular Signals

\- SCSS



\*\*Backend\*\*

\- C#

\- ASP.NET Core Web API (.NET 10)

\- Controllers

\- Entity Framework Core

\- SQL Server LocalDB



\*\*Other tools\*\*

\- Git and GitHub

\- Swagger / OpenAPI

\- xUnit



\## Features (planned)



\- View a coffee menu

\- Customize coffee size, milk type and quantity

\- Add and remove products from a shopping cart

\- Register, log in and log out

\- Place an order

\- View personal order history



\## Project structure



\- `backend/` — ASP.NET Core Web API

\- `frontend/` — Angular application
